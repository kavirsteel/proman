کاربان — نسخه مستقل cPanel / PHP / MySQL

نیازمندی‌ها
- PHP 8.1 یا جدیدتر (پیشنهاد: 8.3)
- افزونه‌های pdo_mysql، session و json
- MySQL 5.7+ یا MariaDB 10.3+ با InnoDB و utf8mb4
- Apache یا LiteSpeed با پشتیبانی .htaccess
- HTTPS فعال
- روی هاست به Node.js، Cloudflare یا حساب ChatGPT نیاز نیست.

نصب
۱. از cPanel > MySQL Database Wizard یک دیتابیس خالی و کاربر مخصوص آن بسازید.
۲. کاربر را به دیتابیس اضافه کرده و ALL PRIVILEGES بدهید. پیشوند اکانت را در نام کامل دیتابیس و کاربر فراموش نکنید.
۳. فایل ZIP را در public_html یا پوشه‌ای مانند public_html/karban آپلود و Extract کنید. فایل index.php باید مستقیماً در پوشه مقصد باشد.
۴. HTTPS را فعال کرده و آدرس https://your-domain/karban/install.php را باز کنید (اگر در ریشه نصب شده، /karban را حذف کنید).
۵. مشخصات دیتابیس و نام، ایمیل و رمز عبور مدیر کل را وارد کنید. رمز مدیر کل باید حداقل ۱۰ کاراکتر باشد.
۶. بعد از نصب موفق، install.php را از File Manager حذف کنید. نصب فقط یک بار انجام می‌شود.
۷. به آدرس برنامه بروید و با ایمیل و رمز انتخاب‌شده وارد شوید.
۸. اعضا را از «اعضای تیم» اضافه کنید؛ هر عضو ایمیل و رمز مستقل دارد. رمز را به صورت امن به خود فرد بدهید. ایمیل دعوت خودکار ارسال نمی‌شود.

نصب در پوشه زیرمجموعه پشتیبانی می‌شود. آدرس API و فایل‌های برنامه نسبی هستند.
فونت آنلاین است و در صورت عدم دسترسی، Tahoma به‌صورت جایگزین استفاده می‌شود.

امکانات
- چند مدیر کل، مدیر پروژه و کاربر
- نمایش کارتی یا جدولی پروژه‌ها
- جدول تسک‌ها و فیلتر منویی وضعیت
- توضیحات متعدد با موعد مستقل، نمایش آخرین توضیح و مرور سوابق
- گزارش کلی، پیشرفت پروژه، حجم کار، تسک‌های عقب‌افتاده و موعدهای پیش رو
- حذف پروژه یا تسک با تأیید؛ حذف پروژه شامل تسک‌ها می‌شود
- نگهداری سابقه حذف و تغییرات با نام شخص و زمان
- بررسی دسترسی در PHP، رمزهای هش‌شده، نشست امن و CSRF

دیتابیس
نصب‌کننده جدول‌ها را ایجاد می‌کند؛ واردکردن SQL جداگانه لازم نیست.
جدول karban_users برای ورود، karban_workspace برای اطلاعات پروژه‌ها و سوابق، karban_login_attempts برای محدودیت تلاش ورود است.
اطلاعات کاری به‌صورت JSON در یک رکورد ذخیره می‌شوند و تغییرات با تراکنش و قفل ردیف انجام می‌شود. این نسخه مناسب تیم کوچک و متوسط است؛ برای بار بالا و سوابق بسیار زیاد باید ساختار داده‌ها تفکیک شود.

پشتیبان‌گیری و انتقال
از دیتابیس MySQL و config.php پشتیبان بگیرید. ZIP شامل داده‌های نسخه آنلاین قبلی نیست؛ این نصب از دیتابیس خالی شروع می‌کند.
برای نصب موجود، config.php را نگه دارید و نصب‌کننده را دوباره اجرا نکنید.
فایل config.php دارای رمز دیتابیس است؛ آن را منتشر نکنید. پوشه را ۷۵۵ و فایل‌ها را ۶۴۴ نگه دارید؛ config.php با دسترسی ۶۰۰ ایجاد می‌شود. از دسترسی ۷۷۷ استفاده نکنید.

رفع اشکال
- خطای ۵۰۰ بلافاصله پس از آپلود: نسخه PHP و بخش Errors در cPanel و پشتیبانی Require all denied در .htaccess را بررسی کنید. در بعضی هاست‌ها Options -Indexes مجاز نیست؛ در این صورت فقط همان خط را حذف کنید.
- خطای دیتابیس: نام کامل همراه پیشوند، مجوز کاربر، آدرس سرور MySQL و فعال‌بودن pdo_mysql را بررسی کنید.
- بعد از انتقال به دامنه جدید: از حساب خارج شده و دوباره وارد شوید.
- فراموشی رمز: بازیابی ایمیلی در این نسخه وجود ندارد؛ رمز را مدیر سرور با هش ساخته‌شده توسط password_hash در ستون password_hash تغییر می‌دهد.

وضعیت بررسی
ساخت production رابط React موفق بود. محیط تولید این بسته، مفسر PHP و MySQL نداشت؛ نصب و اجرای PHP/MySQL روی هاست واقعی هنوز آزمایش نشده است. پیش از واردکردن داده مهم، ایجاد کاربر، پروژه، تسک، توضیح، کنترل دسترسی و حذف را روی هاست خودتان بررسی کنید.

کد توسعه
پوشه _source فقط برای توسعه رابط است و با .htaccess از دسترسی وب بسته شده؛ می‌توانید پس از نگهداری نسخه پشتیبان، آن را از هاست حذف کنید.
برای بازسازی رابط در کامپیوتر توسعه‌دهنده، Node.js 22.13+، npm install و npm run build لازم است؛ خروجی build/assets را در assets کپی کنید.
کد PHP در فایل‌های ریشه بسته قرار دارد.
